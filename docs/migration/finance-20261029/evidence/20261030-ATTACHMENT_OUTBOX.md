Draft+source URI/copy metadata are durable before file I/O. The source URI grant is persisted when supported, and provider revocation is still handled explicitly. Immutable encrypted blob UUID is separate from record/operation UUID; transaction record+outbox binds exactly that blob and its reviewed byte metadata. A changed/deleted source or new download never changes an older operation's bytes. Late ACK preserves independent blob binding. Missing/corrupt copies are held before network with IDs/hash retained. Copy/file finalization and SQL are separate boundaries; completed encrypted copy can resume metadata after a crash. Failed/partial copies, private orphans, logout/role/scope/epoch holds are retained, not purged.

Operational file/policy/audit kinds are explicitly whitelisted for workers; finance remains manager-only. Parent-version rejection requires explicit new reviewed operation, preserving old operation/archive/blob. Configuration/count/closed/local-copy holds support explicit retry of the same immutable operation where applicable. Cancel uses JSON/reason, independent of upload configuration. Downloads are bounded by accepted metadata and copied directly to encrypted storage before checksum validation/READY; download failure does not turn accepted metadata into a draft.
