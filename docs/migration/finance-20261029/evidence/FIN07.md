## Outcome dan AC

Riwayat native mempunyai filter GH/musim/kelompok/jenis/tanggal WIB/status, filter sebelum pagination50, urutan waktu kejadian dan tie UUID; draf waktu belum sah memakai waktu penyimpanan. Detail/audit menampilkan aktual, bahan/satuan, pencatat, versi, before/after dan seluruh alasan acuan. Audit server scoped paginated, cache terenkripsi diberi waktu pemeriksaan/last-known saat offline. Actor name saat dibaca, actor UUID stabil.

Pengelola dapat mengantrekan pembatalan dan close/reopen musim dengan alasan/version. Worker tidak mendapat cancel; server menolak cancel pekerja, koreksi catatan orang lain, akses lintas GH dan musim tertutup. Pembatalan bukan hard delete, queued belum berarti server accepted/cancelled.

Konflik dibekukan lokal/server untuk review. Use-server mengarsipkan lokal dan SUPERSEDED operasi lama tanpa mutation baru. Keep-local wajib alasan serta preserve/refresh; operation baru berbasis versi server yang ditinjau, entity ID tetap. Perubahan local revision/server version sesudah review ditolak. Operasi REJECTED validation hanya diganti melalui review eksplisit; envelope lama tetap. Retry season_closed memakai UUID/hash/payload asli setelah status musim ditinjau; scope/epoch hold tidak dilewati.

SQLite schema4 additive dari1/2/3: metadata filter/urutan dan encrypted local revision archive. Transaksi detail membaca record/pending/arsip konsisten. Hasil async tidak membuka ulang detail yang sudah diganti/ditutup. ACK/error terlambat tidak downgrade versi atau mengaktifkan SUPERSEDED. Worker setelah role turun tidak bisa membaca/mengirim data pengelola; antrean lama disimpan dan ditahan. Setelah batch accepted, coordinator menarik perubahan agar context musim/master diperbarui.
