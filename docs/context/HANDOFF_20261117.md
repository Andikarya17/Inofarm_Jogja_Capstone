## Menjalankan

```powershell
./scripts/start-backend-for-studio.ps1      # MySQL 3307 + Laravel 8000 untuk emulator/ponsel (hanya start)
./scripts/test-backend.ps1                  # PHPUnit, hanya ke inofarm_test
./scripts/build-android.ps1 -JavaHome "C:/Program Files/Eclipse Adoptium/jdk-25.0.4.101-hotspot"
python scripts/check-finance-context.py     # cek tautan context sebelum commit docs
```

Database pengguna `inofarm_finance_local` dan `inofarm_local` tidak boleh di-reset, migrate:fresh, seed atau restore untuk pengujian. Migration ke database aplikasi hanya setelah backup (`scripts/backup-mysql.ps1`) dan izin pengguna.

## Preferensi kerja pengguna

- Bahasa percakapan dan dokumen: Indonesia, kalimat lugas.
- UI/frontend: pakai skill `impeccable` dan `antislop*`; **jangan** pakai `ponytail` untuk pekerjaan UI. Arah visual "Canopy" (forest + krem, dock gelap dengan Catat di tengah, Plus Jakarta Sans) sudah disetujui; ringkasannya di `DESIGN.md`.
- Dosen pembimbing terutama meninjau halaman pengelola.
- Setiap klaim harus membedakan bukti baru dari bukti lama, dan fixture/emulator dari backend nyata/perangkat fisik.
