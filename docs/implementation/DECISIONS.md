## Keputusan teknik

- Modul `android/`, `backend/`, `firmware/`; package Android `com.inofarm.jogja`. Workspace sekarang memiliki Git; perbaikan audit dikerjakan pada `codex/audit-fixes-t1-t7`. Sebanyak 175 file staged awal dipertahankan; tidak ada stage/commit/push/deploy. Workflow GitLab kampus tetap terbuka.
- Target awal satu tandon dan satu producer. Backend mengikat akun owner/leader dan device ke tandon secara server-side. Provisioning lewat CLI lokal, tanpa self-registration/login pekerja.

History mempertahankan snapshot aturan, fase dan shift saat event sumber; tidak direvalidasi otomatis. Replay memilih versi historis menurut confirmation time. Initial produksi tanpa fase, aturan, jadwal atau pekerja.
- Request maksimum 16 KiB (pilihan teknis reversible), page maksimum 100. Stable UUID event dan canonical payload hash: replay identik mengembalikan ACK sama, benturan isi 409. ACK berarti transaction persisted.

## Optimasi Android — 13 Oktober 2026

Otorisasi adalah permintaan performa pengguna pada tanggal ini, bukan perluasan backend/firmware/React. MinSdk26 dan dependency/toolchain dipertahankan. Restore selesai sebelum refresh awal untuk menghindari balapan cache/server; state awal statis restoring, bukan login. IO memegang file/Keystore/preferences/setup request dan JSON cache bounded di bawah storage lock; Default memegang parsing API/mapping DTO. SessionStore memegang snapshot immutable memori dan generation; pasangan base/token request dibekukan bersama. Known expiry juga diperiksa sesudah response sebelum state diterbitkan. Purge dimulai UNDISPATCHED lalu NonCancellable IO, agar penutupan ViewModel tidak membatalkan pekerjaan yang sudah dimulai; process kill mendadak sebelum disk purge selesai tetap belum diverifikasi.

Schema2 dipilih sebagai enam AtomicFile AES-GCM per-resource, tanpa Room/dependency baru. Schema1 diinvalidasi pada read/write tanpa menghapus sesi; cache offline lama bisa tidak tersedia sampai refresh berhasil.
