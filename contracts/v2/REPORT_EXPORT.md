# FIN14 immutable report export v1

GET `/api/v2/report-exports/{id}/{pdf|csv}?expected_snapshot_hash={sha256}`. Only accepted season_report/investment_report snapshots. A current manager with GH assignment and active token is required, checked both before generation and immediately before response; epoch changes abort409. Wrong viewed hash409, unknown query keys422, inaccessible IDs404, worker403, corrupt full/source hash500. No filename/path/font/HTML configuration accepted from callers. No public/private-file bypass URL is created. HTTP private/no-store, nosniff, exact Content-Length, attachment filename derived solely from canonical report ID/kind; snapshot SHA256 and byte SHA256 headers mandatory. A file is never generated from live source aggregation.

The document is the exact verified stored full snapshot with snapshot_hash and export_schema_version=finance-snapshot-export-v1 added as export metadata. Source revisions, scope/filter, coverage/known pending, scenario version, formula version, inputs, independent metric status/reasons, assumptions and exact_fraction/IRR solver detail stay unchanged. Source correction/cancellation does not modify an old export. Read-only authorization/generation does not create receipt/audit/operation duplicates.

PDF: Dompdf3.1.6 pinned; PHP8.5/DOM/mbstring verified locally. All human content HTML-escaped, no caller CSS/HTML accepted, remote resources/PHP/JavaScript disabled, file protocol chroot limited to bundled fonts; cache outside public directory. Unicode DejaVu Sans, readable summary and ordered detailed metrics, complete source appendix and hash identity. Display numbers localized by string grouping only, no float math; original raw decimal strings remain in detail. Bytes may carry PDF-library metadata, so snapshot hash, not cross-run PDF byte identity, binds the report. Byte checksum verifies each individual transfer.

CSV: UTF-8 BOM, RFC4180 quoting and CRLF, columns field,type,value,json_value,text_escaped. Field is an RFC6901-style path with ~0/~1 escaping; empty arrays, null, booleans, integers and decimal strings remain typed in json_value using canonical JSON. This column losslessly reconstructs the export document. Human value cells that could start a spreadsheet formula (including leading controls/Unicode whitespace) receive an apostrophe and text_escaped=true. Signed money strings are never converted to float or silently rounded. Consumers needing exact data use json_value, rather than interpreting the spreadsheet-visible apostrophe as part of a numeric amount.

Android: download actions only on accepted immutable report views. ACTION_CREATE_DOCUMENT chooses destination; cancel does not download or report success. Pending selection contains account scope/report ID/GH/kind/hash/format, not credentials. Current local session/generation/role/GH/epoch state and accepted hash are checked before HTTP and again before invoking destination. Authenticated no-redirect transfer validates MIME, snapshot header, bytes SHA256, bounded length and PDF signature before writing. Technical in-memory cap16MiB and transfer deadline120s; errors leave the stored report intact and never claim a complete saved file. Files chosen by the user are deliberate exports; no broad storage permission or public server location is introduced.
