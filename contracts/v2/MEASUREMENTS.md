# Pengukuran manual — keputusan pengguna 2 November 2026

`activity_type=measurement` memakai envelope activity v2, endpoint mutation/sync, UUID, base_version, alasan koreksi/cancel, scope dan ledger yang sama. Submit baru memerlukan `work_state=completed`, `manual_ec` (mS/cm) dan `manual_ppm` (ppm), decimal string nonnegatif DECIMAL(20,6); `materials=[]`, pH opsional0–14. Android menerima koma desimal pada formulir lalu menormalisasi di batas wire; API hanya titik, tanpa konversi EC↔PPM/default/ambang. Draf mentah belum lengkap tetap persisten. Payload antrean lama dan hash tidak ditulis ulang.

Schema15 menambah `activities.manual_ec` nullable dan index pencarian. Tidak ada backfill EC atau perubahan migration1–14. Kegiatan nutrisi lama tetap membutuhkan bahan dan PPM/pH; tidak dipaksa menjadi pengukuran baru. Audit/reference snapshots/receipt/feed baru memuat EC; snapshot historis immutable boleh tidak mempunyai key EC.

`GET measurements/latest?planting_group_id=UUID`: scoped read di bawah commit-order lock, hasil `{data: activity|null, calendar: "Asia/Jakarta", as_of: timestamp}`. Query seluruh kegiatan grup, active+completed+PPM tersedia, occurred_at sebelum awal besok WIB, order occurred_at DESC lalu UUID DESC, limit1; tidak memakai created_at, waktu sync atau halaman riwayat. Pilihan ini setara hari ini→kemarin→sebelumnya. Histori hanya PPM tetap satu record dengan EC tidak tersedia.

Dashboard Android memakai seluruh cache dari stable paginated pull, bukan list1000 riwayat. DAO memindai kandidat scoped dalam batch100 berurutan sampai pengukuran valid ditemukan. Tidak mencampur group/GH; season adalah parent group immutable. Accepted atau queued lengkap boleh muncul; draf mentah, cancelled/skipped, cancel queued, rejected/conflict/auth/scope/epoch hold dikecualikan. Queued lengkap dilabel **Belum tersinkron**. Empty **Belum ada pengukuran**, legacy EC **EC belum tersedia**. Tepat dua kartu EC/PPM, tanpa kartu pH; HSS/HST dan acuan adalah konteks.

Tanggal/jam WIB, input manual, actor accepted dari sesi server. Queued create menandai akun ini menunggu penerimaan server; queued koreksi mempertahankan pencatat awal dari accepted server body, termasuk koreksi oleh pengelola lain. Data lama: **Belum ada pengukuran hari ini. Data [tanggal/jam].** Koneksi/data tersimpan dan sinkron terakhir terpisah, tidak mengklaim server paling mutakhir. UI reload saat aktivitas/pull berubah, dan memeriksa cache setiap5detik saat STARTED agar background pull/revoke dan pergantian hari tercermin. Scope/account keys dan session generation mencegah respons akun lama tampil; tidak clear/purge draf.

Server dan Android harus diperbarui bersama sebelum memakai tipe baru. Aplikasi lama masih bisa membaca tipe yang dikenal; rollout source ini bukan izin deploy. Backup inventory lossless mengikutsertakan kolom baru; restore paket schema14 ke target schema15 harus memakai staging/schema yang sesuai dan rekonsiliasi, bukan menurunkan/drop schema.
