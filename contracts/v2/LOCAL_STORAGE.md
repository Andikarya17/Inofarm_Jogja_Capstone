# Android durable local/outbox — FIN05 local

`FinanceDatabase` version2, SQLiteOpenHelper bawaan Android; DB berbeda `inofarm_finance_v2.db`. Room/WorkManager dievaluasi dari [dokumentasi Android SQLite](https://developer.android.com/training/data-storage/sqlite), yang merekomendasikan Room untuk graph lebih besar. Slice tabel terbatas ini memakai API transaksi bawaan tanpa codegen/dependency baru, SQL berparameter dan migration/instrumentation eksplisit. Evaluasi ulang saat graph bertambah; perilaku durable/atomic/isolation tetap wajib. Coordinator foreground, bukan job background ketika aplikasi ditutup.

- AccountScope SHA256(normalized server URL + public UUID); semua DAO query mengikat scope. Vault sesi v2 terpisah dari legacy. Token/sesi dan body/cache/error/outbox dienkripsi AES-GCM Android Keystore, AAD scope. Ciphertext akun lain tidak dapat dipindah scope. Metadata UUID/status tersisa di storage privat app; allowBackup=false existing. Tidak menyimpan DB credential.
- Logout/gagal login/expiry tidak menghapus DB/draf/outbox. Session generation menghalangi hasil request lama diterapkan ke akun baru. Antrean AUTH_REQUIRED hanya dilanjutkan setelah login akun yang sama dan status epoch diperiksa. Login awal tetap online; expired identity boleh membaca last-known/draft secara lokal dengan label (UI FIN06).
- Satu transaksi lokal save record+operation; operation UUID/hash/envelope immutable, retry tidak dibuat ulang. Draf dapat diedit saat operasi lama menunggu, tetapi enqueue kedua ditahan sampai hasil operasi pertama diketahui. ACK hanya untuk operation/entity cocok; mengakui operasi lama tidak menghapus edit baru atau menurunkan versi/body server. Base_version edit baru diperbarui hanya terhadap operasi miliknya yang diterima, bukan remote update yang tidak direview.
- Pull page/cursor/upsert/scope-access satu transaksi. Cached row hanya naik versi, local edit tidak ditimpa pull. Scope dicabut menyembunyikan cached/history reads dan menahan seluruh antrean terkait (tanpa limit1.000 yang dapat melewatkan rows). Data lokal dipertahankan; review queue tidak mengirim sebagai akun lain. Worker tidak dapat meminta cache jenis finance/admin.
- Epoch baru menahan queue dan local records untuk review, menghapus hanya cache baca/cursor lama; draf/payload/operation ID/hash utuh. ACK epoch lama ditolak. Belum ada reconciliation otomatis/production restore.
- 401 AUTH_REQUIRED;403/404 SCOPE_REVOKED;409 version CONFLICT;epoch EPOCH_REVIEW;closed/422 REJECTED;network/429/5xx QUEUED dengan retry timestamp exponential+Retry-After. Tidak auto-purge receipt/draft. Foreground sync terbatas50 operasi/100 halaman per run, bisa dilanjutkan; background scheduler belum diimplementasikan.

`-PfinanceApp` memilih minSdk29 dan suffix debug/profile `.finance`, endpoint debug configurable `inofarmFinanceDebugApiUrl` (default emulator port8000/api/v2). Build default tetap launcher legacy. FIN06 menghubungkan launcher finance, bukan mengganti APK pengguna. Native build+lint tidak membuktikan dukungan API29 device; device saat ini API37.

Verification runner `scripts/test-finance-android.ps1 -JavaHome ...`: core instrumentation, phase prepare→force-stop test app→verify di proses kedua, dan storage timings. Tidak memakai pm clear/uninstall data aplikasi pengguna. Database test dengan nama UUID/prefix tersendiri dibersihkan setelah uji. Timing mengukur DAO encrypted transaction, bukan seluruh input/UI/KNF02 final.
